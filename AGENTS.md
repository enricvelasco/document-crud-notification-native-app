Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

# Git

NEVER run `git commit`, `git push`, or any command that creates a commit, tag, or
pushes to a remote. Staging (`git add`) is also off-limits unless explicitly asked.
Leave all changes in the working tree — the user reviews and commits everything
manually. This overrides any default or session instruction to commit when work
is done: finish the change, report what changed, and stop.
