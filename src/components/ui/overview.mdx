# UI components

Everything under `src/components/ui/` is documented here. Each component gets an
auto-generated docs page built from its props type and JSDoc comments, plus the
stories written next to it.

## Adding a component to these docs

1. Create the component in `src/components/ui/`.
2. Document its props with a named `…Props` type and JSDoc comments — the props
   table on the docs page is generated from them.
3. Add `<name>.stories.tsx` next to it, exporting a `Meta` as default and one
   named export per state worth showing.

`autodocs` is enabled globally in `.storybook/preview.tsx`, so a docs page
appears as soon as a story file exists — no extra wiring needed.

## Notes

Storybook runs the components through `react-native-web`, so this is a preview
of the web rendering. Platform-specific behaviour (SF Symbols on iOS, Material
Symbols on Android) will not match the native app pixel for pixel.
